# src/js/

## Descripción
Toda la lógica JavaScript de la app, organizada por responsabilidad.

## Archivos de este directorio
| Archivo | Función |
|---|---|
| `app.js` | Orquestador: importa todos los componentes y los monta en el DOM. Inicializa el catálogo, header, hero, footer, carrito. |
| `config.js` | Constantes globales: `NRO_WHATSAPP`, `URL_SHEETS`, `NOMBRE_NEGOCIO`. **Editar aquí** al configurar el proyecto. |

## Carpetas hijas
| Carpeta | Propósito |
|---|---|
| `data/` | Capa de datos: productos y carrito |
| `components/` | Componentes UI (header, hero, catalog, cart, etc.) |
| `utils/` | Funciones auxiliares (WhatsApp, Sheets, formato) |
